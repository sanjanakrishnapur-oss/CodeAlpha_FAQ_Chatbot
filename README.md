 AI FAQ Chatbot

About the Project

The AI FAQ Chatbot is a Python-based application that answers frequently asked questions related to Artificial Intelligence, Python, programming, and technology.

It uses Natural Language Processing (NLP) techniques and similarity matching to identify the most relevant question and display its answer.

Features

- Interactive chatbot interface
- User-friendly Streamlit application
- FAQ-based question answering
- Text preprocessing
- Similarity-based question matching
- Instant answer display

Technologies Used

- Python
- Streamlit
- NLP
- Scikit-learn
- JSON

Installation and Setup

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project folder:

cd CodeAlpha_FAQ_Chatbot

3. Install dependencies:

pip install -r requirements.txt

4. Run the application:

python -m streamlit run app.py

5. Open the local URL displayed in the terminal.

How to Use

1. Open the chatbot application.
2. Enter a question in the input box.
3. Click the Get Answer button.
4. View the chatbot response.
